# OWP — Operation Workflow Protocol

**نسخه: 1.0.0 | وضعیت: نسخه پایه | مجوز: CC BY 4.0**

پروتکل گردش کار Operation، استانداردی سبک و مستقل از فناوری برای مدیریت توسعه نرم‌افزار با عامل‌های هوش مصنوعی است. هدف آن کاهش تحلیل تکراری، حفظ تصمیم‌های معتبر، مصرف متناسب اعتبار، بازبینی مستقل و کنترل مالک پروژه بر اقدامات حساس است.

## شروع سریع

۱. [راهنمای فارسی شروع و استفاده](docs/GETTING_STARTED.md) را بخوانید.
۲. نسخه مشخصی از [Core](operation-workflow/references/OPERATION_WORKFLOW.md) و [Skill](operation-workflow/SKILL.md) را انتخاب کنید.
۳. [قالب Profile](operation-workflow/assets/PROJECT_PROFILE.template.md) را برای پروژه خود کامل کنید و یک چت یا عامل اصلی با نام Operation تعیین کنید.
۴. از Operation بخواهید طبق OWP کار کند؛ تسک‌های محدود و دقیق را به عامل توسعه (مثلاً Codex) بسپارید.

مالک انسانی تصمیم‌ها و مجوزهای حساس را کنترل می‌کند؛ Operation تحلیل، طراحی، واگذاری و بازبینی را هماهنگ می‌کند؛ عامل توسعه پیاده‌سازی و تست را انجام می‌دهد. زبان پیش‌فرض ارتباط انسانی فارسی و زبان وظایف و گزارش‌های بین عامل‌ها انگلیسی است؛ در هر پروژه قابل تنظیم است. Skill مخصوص Operation است و به‌خودی‌خود هیچ مجوز ابزار یا دسترسی خارجی ایجاد نمی‌کند.

## سلب مسئولیت

OWP یک پروتکل عملیاتی مستقل برای توسعه نرم‌افزار با کمک هوش مصنوعی است و هیچ تضمینی درباره صحت، امنیت، قابلیت اطمینان یا انطباق خروجی عامل‌های هوش مصنوعی ارائه نمی‌کند.

ارزیابی نتایج، مدیریت مجوزها، حفاظت از اطلاعات و نظارت بر اقدامات حساس بر عهده کاربران و مالکان پروژه‌هاست. استفاده از OWP جایگزین بازبینی انسانی و ارزیابی تخصصی نیست.
